# React 开发规范

## 组件规范

- 每个文件一个组件
- 只使用函数组件——禁止类组件
- 组件名使用 PascalCase
- 组件超过 200 行就提取
- 逻辑和展示分离（业务逻辑放自定义 Hooks）

## Hooks 规范

- 禁止在条件语句或循环中调用 Hook
- 自定义 Hook 以 `use` 为前缀
- `useEffect` 依赖数组必须完整且准确
- 多个相关 `useState` 时优先使用 `useReducer`
- `useMemo` 和 `useCallback` 只在性能分析证明有必要时使用

## 状态管理

- 将状态提升到最近的公共祖先
- 优先本地状态——不要一上来就用全局状态
- 状态与使用它的组件放在一起
- 超过 2 层的 prop drilling 考虑使用 Context 或组合

## 性能规范

- 列表 key 必须稳定且唯一（禁止使用 index）
- `React.memo` 用于频繁渲染且 props 不变的组件
- 避免在渲染中创建对象/函数——会导致不必要的重渲染
- 大型客户端组件使用 `React.lazy` 懒加载

## 事件处理

- 事件处理函数命名 `handle{Event}`：`handleClick`、`handleSubmit`
- 性能敏感的列表中禁止在 JSX 中内联箭头函数

## TypeScript 集成

- 明确为组件 props 声明类型——禁止隐式 any
- 谨慎使用 `React.FC`——直接为函数标注类型
- children prop 类型使用 `ReactNode`
