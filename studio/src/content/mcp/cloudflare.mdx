## 这个 MCP 能做什么？

Cloudflare 官方发布的 MCP 服务器，让 Claude 可以直接管理你的 Cloudflare 账户资源，包括 Workers、R2 对象存储、KV 存储、D1 数据库等。

## 典型用途

**Workers 开发**：「帮我写一个 Cloudflare Worker 实现 API 代理，然后部署」

**R2 管理**：「列出 R2 存储桶中的文件，删除超过 30 天的日志」

**DNS 配置**：「帮我添加一条 CNAME 记录指向这个地址」

**KV 操作**：「读取 KV 命名空间中的配置，更新缓存策略」

**D1 查询**：「查询 D1 数据库中的用户数据」

## 配置说明

在 Cloudflare 仪表板 → API Tokens 创建具有相应权限的 API Token。
