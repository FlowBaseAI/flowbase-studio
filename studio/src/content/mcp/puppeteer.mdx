## 这个 MCP 能做什么？

Puppeteer MCP 使用无头 Chrome 浏览器，适合需要截图、PDF 生成或处理 JavaScript 渲染页面的场景。

## 典型用途

**网页截图**：「截取这个网页当前状态的截图」

**PDF 生成**：「把这个网页转成 PDF 文档」

**动态内容抓取**：「抓取这个 SPA 应用里的数据（需要 JS 渲染）」

**视觉测试**：「对比两个版本页面的视觉差异」

## Playwright vs Puppeteer

- Playwright MCP：通过 Accessibility Tree 操作，更适合 AI 交互
- Puppeteer MCP：更适合截图、PDF 等图形化输出
