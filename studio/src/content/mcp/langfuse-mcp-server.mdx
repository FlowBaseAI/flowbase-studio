## 这个 MCP 能做什么？

Langfuse LLM 观测 MCP 适合把 observability 能力接入 Claude Code Workspace，为国内团队提供可选、可配置、可导出的 MCP 工具。

## 国内团队使用场景

- 作为 FlowBase Studio Workspace 数据源
- 服务 AI Agent 的安全、观测、RAG、搜索或身份场景
- 为国内团队提供配置示例和权限边界

## 配置示例

```json
{
  "mcpServers": {
    "langfuse": {
      "command": "npx",
      "args": [
      "-y",
      "mcp-server-langfuse"
]
    }
  }
}
```

## 使用建议

- 先在测试环境连接。
- 只开放最小权限。
- 涉及身份、日志或数据检索时保留审计记录。
