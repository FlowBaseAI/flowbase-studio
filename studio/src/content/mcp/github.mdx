## Overview

The GitHub MCP server lets Claude Code interact with GitHub repositories programmatically. You can search code, read files, manage issues, create pull requests, and automate your entire GitHub workflow.

## Use Cases

- **Code Review Automation**: Ask Claude to review PRs and post inline comments
- **Issue Management**: Auto-triage issues, assign labels, and suggest fixes
- **Repository Analysis**: Analyze code quality, find vulnerabilities, summarize changes
- **PR Creation**: Generate commit messages and create PRs from local changes

## Configuration

Set your `GITHUB_TOKEN` environment variable with a personal access token that has `repo` scope.

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_your_token_here"
      }
    }
  }
}
```
