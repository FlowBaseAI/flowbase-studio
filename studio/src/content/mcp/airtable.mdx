## 这个 MCP 能做什么？

Airtable MCP 让 Claude 直接访问和操作 Airtable 数据库，适合使用 Airtable 管理内容、项目或客户数据的团队。

## 典型用途

**内容管理**：「查看编辑日历中本周需要发布的内容」

**数据录入**：「把这批数据批量添加到客户管理表格」

**数据分析**：「分析产品反馈表格，统计最常见的用户痛点」

**报告生成**：「根据项目追踪表格生成本周进度报告」
