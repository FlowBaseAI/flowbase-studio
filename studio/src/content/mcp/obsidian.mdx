## 这个 MCP 能做什么？

Obsidian MCP 让 Claude 直接连接到你的 Obsidian 笔记库，可以读取、搜索和写入笔记，帮你更好地利用已有的知识积累。

## 典型用途

**知识检索**：「在我的笔记里找关于这个话题的所有记录」

**笔记生成**：「根据今天的学习内容，写一篇笔记保存到我的 Obsidian」

**知识连接**：「找出我的笔记中和这个主题相关的内容，建立联系」

**内容整理**：「整理我关于这个项目的散乱笔记，生成结构化文档」

## 配置说明

将你的 Obsidian Vault 路径传入：

```json
{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "mcp-obsidian", "/你的Vault路径"]
    }
  }
}
```
