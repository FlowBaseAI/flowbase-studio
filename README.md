- Static Deployment

## Why FlowBase Studio

Claude Code projects often require several configuration files before a workspace is ready:

- `CLAUDE.md`
- MCP Config
- Skills Files
- Rules Files

FlowBase Studio brings these pieces into a visual workspace, so teams can configure projects, browse libraries, and export ready-to-use configuration without managing every file by hand.
