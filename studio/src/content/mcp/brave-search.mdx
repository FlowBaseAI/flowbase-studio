## Overview

Brave Search MCP gives Claude access to real-time web search. Claude can search for current events, documentation, tutorials, and any web content beyond its training cutoff.

## Use Cases

- **Research Agent**: Search and synthesize information from the web
- **News Monitoring**: Get current news on any topic
- **Technical Research**: Find latest docs, changelogs, and tutorials
- **Fact Checking**: Verify claims with current web sources

## Setup

Get a free API key at [brave.com/search/api](https://brave.com/search/api/).
