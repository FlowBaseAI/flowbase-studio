## 这个 MCP 能做什么？

Time MCP 解决了 LLM 不知道当前时间的根本问题，让 Claude 能够获取准确的实时时间，并进行时区转换。

## 典型用途

**时间感知任务**：「帮我安排今天下午的日程」

**时区转换**：「北京时间下午 3 点，纽约是几点」

**日期计算**：「今天距离春节还有多少天」

**时间标记**：生成包含准确时间戳的日志和报告

## 适用场景

所有需要 Claude 知晓当前时间的场景，特别是日程管理、定时任务和时效性内容生成。
