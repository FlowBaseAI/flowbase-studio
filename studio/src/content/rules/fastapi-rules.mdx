# FastAPI 开发规范

## 项目结构

```
app/
  main.py          # 应用工厂
  routers/         # 按业务领域分组的路由处理器
  models/          # SQLAlchemy 数据模型
  schemas/         # Pydantic Schema
  services/        # 业务逻辑
  dependencies/    # FastAPI 依赖注入
  core/            # 配置、安全、数据库连接
```

## 路由规范

- 用 Router 的前缀和标签将相关端点分组
- 使用正确的 HTTP 方法——禁止什么都用 POST
- URL 中包含版本：`/v1/users`
- 用 `status_code` 参数返回合适的状态码

## Pydantic Schema

- 请求和响应 Schema 分开（不要复用）
- 所有数据传输使用 `BaseModel`
- 严格进行数据验证——禁止跳过
- 跨字段验证使用 `model_validator`

## 异步编程

- I/O 密集型端点使用 `async def`
- CPU 密集型操作使用 `def`（会在线程池中运行）
- 异步函数中禁止使用 `time.sleep`——使用 `asyncio.sleep`
- 数据库操作必须 await

## 安全规范

- 认证依赖使用 `OAuth2PasswordBearer`
- 密码使用 `bcrypt` 加密——禁止明文存储
- JWT Token 必须有过期时间——在依赖中验证
- 敏感端点加速率限制

## 依赖注入

- 数据库 Session、认证用户、分页等使用依赖注入
- 可复用逻辑使用 `Depends()`——禁止复制粘贴
- 触发即忘操作使用后台任务（Background Tasks）
