## 这个 MCP 能做什么？

EverArt MCP 让 Claude 能够根据文字描述生成 AI 图像，将图像生成能力直接集成到 Claude Code 工作流中。

## 典型用途

**内容配图**：「为这篇博客文章生成一张封面图」

**设计草稿**：「生成这个 UI 组件的视觉草图」

**创意探索**：「生成几个不同风格的品牌 Logo 概念」

**文档插图**：为技术文档自动生成说明性图片

## 获取 API Key

前往 EverArt 官网注册并获取 API Key。
