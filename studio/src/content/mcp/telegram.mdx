## Overview

Telegram MCP lets Claude interact with Telegram — perfect for building notification bots, AI assistants, and automated messaging workflows.

## Use Cases

- **Notification Bot**: Send automated notifications to Telegram channels
- **AI Bot**: Build a Telegram bot powered by Claude
- **Alert System**: Route system alerts to Telegram
- **Daily Briefings**: Send daily summaries to personal Telegram chats
