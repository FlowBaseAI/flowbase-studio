## 这个 MCP 能做什么？

Neon 是 Serverless PostgreSQL 平台，其官方 MCP 让 Claude 可以直接管理数据库项目、创建分支、运行查询。

## 典型用途

**数据库分支**：「为这次功能开发创建一个数据库分支」

**Schema 管理**：「查看当前数据库 Schema，帮我规划迁移方案」

**查询执行**：「在开发分支上测试这个 SQL 查询」

**项目管理**：「列出所有 Neon 项目，显示各项目的连接信息」

## Neon 核心优势

- 数据库分支（像 Git 一样管理数据库）
- 按需扩展，无访问时自动暂停
- 免费计划对独立开发者友好
