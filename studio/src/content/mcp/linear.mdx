## Overview

Linear MCP lets Claude interact with your Linear workspace — read issues, create tasks, update sprint status, and manage your engineering team's workflow.

## Use Cases

- **Issue Triage**: Automatically categorize and label incoming issues
- **Sprint Planning**: Generate sprint summaries and capacity analysis
- **Bug Reports**: Create well-structured bug reports from error logs
- **Progress Reports**: Generate weekly engineering progress summaries
