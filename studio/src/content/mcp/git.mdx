## Overview

The Git MCP server gives Claude direct access to your local Git repositories. It can read commits, diffs, branches, tags, and history to provide deep codebase context.

## Use Cases

- **Commit Message Generation**: Generate meaningful commit messages from diffs
- **Change Analysis**: Understand what changed between any two commits
- **Code History**: Trace the evolution of specific functions or files
- **Branch Management**: Get summaries of branch differences
