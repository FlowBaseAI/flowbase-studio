## Overview

The Slack MCP server lets Claude interact with your Slack workspace. Read channel history, post messages, search conversations, and build automated team workflows.

## Use Cases

- **Daily Summaries**: Summarize channel activity overnight
- **Auto Responses**: Draft responses to common questions
- **Incident Reports**: Post structured incident updates automatically
- **Team Notifications**: Send formatted notifications from your code
