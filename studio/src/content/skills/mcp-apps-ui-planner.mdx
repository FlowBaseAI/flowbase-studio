## MCP Apps UI 规划员

MCP Apps UI 规划员 面向 2026 年 AI Agent 安全、观测、身份和企业落地场景，强调国内团队可执行的流程和验收标准。

## 适用场景

- MCP UI 设计
- 审批界面
- 数据可视化

## 工作方式

1. 读取任务目标和约束。
2. 检查现有内容和权限边界。
3. 输出执行流程、风险点和验收标准。
4. 需要工具调用时保留证据。

## 输出要求

- 结构化流程
- 风险清单
- 验收标准
- 适合复制到 Claude Code 或 Codex 的任务说明
