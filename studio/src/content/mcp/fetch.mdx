## Overview

The Fetch MCP server allows Claude to retrieve and convert web content to Markdown. It handles HTML-to-text conversion, handles pagination, and respects robots.txt.

## Use Cases

- **Documentation Fetching**: Pull in API docs or library references
- **Article Summarization**: Fetch and summarize web articles
- **API Testing**: Make HTTP requests and process responses
- **Research**: Gather information from multiple web sources
