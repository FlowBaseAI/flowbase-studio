## 这个 MCP 能做什么？

Linear MCP 让 Claude 直接与你的 Linear 工作区交互，自动化项目管理中的重复工作。

## 典型用途

**Issue 创建**：「根据这个 bug 报告，在 Linear 里创建一个详细的 Issue」

**Sprint 摘要**：「总结本 Sprint 的完成情况和剩余工作」

**任务分配**：「把这些待办事项整理成 Linear 任务，分配给相关人员」

**进度报告**：「生成本周的工程进度报告」

## 获取 API Key

在 Linear Settings → API 页面创建 Personal API Key。
