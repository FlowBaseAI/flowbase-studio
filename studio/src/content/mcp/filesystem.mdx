## 这个 MCP 能做什么？

Filesystem MCP 给 Claude 提供安全的本地文件访问能力。你可以精确控制哪些目录可以被访问，Claude 只能在你允许的范围内操作。

## 典型用途

**批量处理文件**：「读取这个目录下所有 .md 文件，统一格式」

**代码生成**：「根据需求写代码，直接保存到指定目录」

**配置管理**：「帮我更新项目里的配置文件」

**内容整理**：「扫描这个文件夹，整理出所有重要信息」

## 配置说明

在命令行参数中指定允许访问的目录路径：

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/你的项目路径"]
    }
  }
}
```

可以指定多个目录：`"/路径1", "/路径2"`
