# SEO 内容规范

## 页面 On-Page SEO

### Title Tag
- 最多 50-60 字符
- 主关键词放在标题开头
- 每个页面必须有唯一标题
- 格式：`主关键词 — 品牌名`

### Meta 描述
- 150-160 字符
- 自然融入主关键词
- 以吸引点击的行动号召结尾
- 每个页面唯一——禁止重复

### 标题层级结构
- 每页只有一个 H1，包含主关键词
- H2 用于主要章节（融入次要关键词）
- H3 用于子章节
- 禁止跳级使用标题

## 内容质量规范

- 可索引页面最少 300 字，支柱内容 1500 字以上
- 主关键词出现在前 100 字内
- 关键词密度 1-2%（禁止关键词堆砌）
- 使用语义变体，而非只用精确匹配
- 直接、完整地回答搜索意图

## 技术要求

- 所有重复/相似内容必须有 Canonical 标签
- 所有图片有 alt 文字（描述性，相关时包含关键词）
- 每篇文章 3-5 个内链
- 引用权威外部来源
- 文章、产品、FAQ 等使用对应 Schema 标记

## URL 结构

- 小写，连字符分隔
- 包含主关键词
- 尽量避免停用词
- 核心页面 URL 层级不超过 3-4 层

## Core Web Vitals 目标

- LCP（最大内容绘制）：2.5 秒以内
- FID（首次输入延迟）：100ms 以内
- CLS（累积布局偏移）：0.1 以内
