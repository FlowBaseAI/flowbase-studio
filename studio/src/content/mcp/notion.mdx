## 这个 MCP 能做什么？

Notion 官方发布的 MCP 服务器，让 Claude 可以直接操作你的 Notion 工作区，包括读取页面、写入内容、查询数据库等。

## 典型用途

**会议记录**：「把这次会议的要点整理成 Notion 页面」

**内容管理**：「在我的内容日历数据库里添加这篇文章的计划」

**知识检索**：「在我的 Notion 笔记里找和这个问题相关的内容」

**日报生成**：「根据今天的工作内容，生成一篇日报保存到 Notion」

## 获取 Token

在 Notion 设置 → Integrations 创建 API 集成，获取 Integration Token。
