# GEO 内容质量规范

## 目标

规定 AI 搜索内容必须覆盖搜索意图、问答结构、引用线索和验证步骤。

## 必须遵守

- 先读取现有项目和内容，不凭空覆盖。
- 涉及生产系统、账号、客户数据和资金流时必须人工确认。
- 生成内容必须去重，避免重复标题、重复资源和重复主题。
- 输出必须包含验证步骤、失败处理和回滚建议。

## 禁止事项

- 禁止绕过构建、schema 或页面抽检。
- 禁止提交 node_modules、dist、日志、临时报告。
- 禁止把普通导航内容伪装成 Studio 工作台资源。
- 禁止为了凑数量制造薄内容。

## 验收标准

- 规则可复制到 Claude Code 项目中执行。
- 能约束 Agent 权限、上下文和输出质量。
- 能服务国内团队的真实业务场景。
