## 这个 MCP 能做什么？

AWS Bedrock KB MCP 让 Claude 检索存储在 Amazon Bedrock Knowledge Base 中的企业私有文档，实现 RAG（检索增强生成）工作流。

## 典型用途

**企业知识检索**：「在公司内部文档中找关于这个系统架构的说明」

**合规查询**：「检索合规手册中关于数据处理的相关规定」

**产品文档**：「根据内部 FAQ 回答用户的常见问题」

**技术支持**：「在技术文档库中找这个错误的解决方案」

## 适用场景

特别适合有大量私有文档、需要 RAG 能力的企业场景。
