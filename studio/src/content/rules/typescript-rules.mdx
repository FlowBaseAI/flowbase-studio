# TypeScript 规范

## 类型安全

- `tsconfig.json` 必须启用 `strict: true`，不允许例外
- 禁止使用 `any`——使用 `unknown` 并做类型收窄
- 非必要不使用类型断言（`as`），必须使用时加注释说明原因
- 对象形状使用 `interface`，联合/交叉类型使用 `type`
- 不应修改的数据使用 `readonly`
- 字面量类型使用 `const` 断言：`as const`

## 函数规范

- 明确标注函数参数和返回值类型
- 顶层函数优先使用函数声明而非箭头函数
- 多签名函数使用重载
- 避免可选参数放在参数列表开头

## 空值处理

- 合适时使用可选链（`?.`）而非 null 检查
- 默认值使用空值合并（`??`）而非 `||`（避免 falsy 陷阱）
- 明确处理 `null` 和 `undefined`，不要隐藏它们
- 优先使用早返回而非嵌套 if-else

## 导入规范

- 仅类型导入使用 `import type`
- 导入分组：外部依赖 → 内部模块 → 类型
- 库文件禁止使用默认导出（使用命名导出）

## 现代语法

- 使用模板字面量类型进行字符串验证
- 使用 `satisfies` 操作符进行类型检查而不扩宽类型
- 使用 `infer` 从泛型中提取类型
