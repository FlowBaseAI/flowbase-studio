## 这个 MCP 能做什么？

browser-use 是 GitHub 上广受好评的 AI 浏览器自动化项目（数万 Star），其 MCP 版本让 Claude 能够像真人一样使用浏览器，完成复杂的多步骤任务。

## 典型用途

**信息搜集**：「帮我搜索并整理这个话题的最新资讯」

**竞品分析**：「访问这几个网站，对比它们的定价方案」

**自动化操作**：「登录这个平台，下载上个月的数据报告」

**内容提取**：「从这个网站提取所有联系方式」

## 环境要求

需要 Python 3.11+ 和 Chromium 浏览器：

```bash
pip install browser-use
playwright install chromium
```
