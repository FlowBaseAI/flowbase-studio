## Overview

The OpenAI MCP gives Claude access to OpenAI's suite of models and APIs, enabling multi-model workflows where each AI does what it's best at.

## Use Cases

- **Image Generation**: Generate images with DALL-E from within Claude
- **Transcription**: Use Whisper to transcribe audio files
- **Embeddings**: Generate text embeddings for semantic search
- **Multi-model Reasoning**: Route specialized tasks to optimal models
