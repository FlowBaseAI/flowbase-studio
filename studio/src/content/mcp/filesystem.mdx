## Overview

The Filesystem MCP server provides Claude with secure, sandboxed access to your local files. You define which directories are accessible, and Claude can read, write, create, and delete files within those boundaries.

## Use Cases

- **Project File Management**: Read and modify project files directly
- **Content Generation**: Write blog posts, docs, and code to disk
- **Data Processing**: Read CSV/JSON files and process data
- **Configuration Management**: Update config files across your project

## Configuration

Specify the directories you want to allow access to as arguments.

```json
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "/your/project/path"]
    }
  }
}
```
