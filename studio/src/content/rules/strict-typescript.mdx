# TypeScript 极严格规范

## tsconfig.json 要求

```json
{
  "compilerOptions": {
    "strict": true,
    "noUncheckedIndexedAccess": true,
    "exactOptionalPropertyTypes": true,
    "noImplicitReturns": true,
    "noFallthroughCasesInSwitch": true,
    "forceConsistentCasingInFileNames": true
  }
}
```

## 零逃生舱口原则

- 禁止 `any`——使用 `unknown` + 类型收窄
- `as` 类型转换必须有说明理由的注释
- `!` 非空断言必须有证明安全的注释
- 禁止 `@ts-ignore`
- `// eslint-disable` 必须附上 Issue 编号

## 穷举模式匹配

```typescript
// 所有联合类型分支必须处理
function assertNever(x: never): never {
  throw new Error(`未处理的情况: ${x}`)
}

switch (action.type) {
  case 'ADD': return handleAdd(action)
  case 'REMOVE': return handleRemove(action)
  default: return assertNever(action.type) // 缺少分支时编译报错
}
```

## Result 类型（不抛出异常）

```typescript
type Result<T, E = Error> =
  | { success: true; data: T }
  | { success: false; error: E }
```

对可能失败的操作使用 Result 类型。真正意外的、无法恢复的错误才使用 `throw`。

## 泛型约束规范

- 所有泛型必须有有意义的约束
- 泛型含义不明显时使用 JSDoc 注释
- 当知道具体形状时，避免使用无约束的 `T`
