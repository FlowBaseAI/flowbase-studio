# Tailwind CSS 规范

## 类名组织顺序

按以下顺序排列工具类：
1. 布局（display、position、float）
2. 尺寸（width、height、padding、margin）
3. 排版（font、text、leading）
4. 视觉（background、border、shadow、opacity）
5. 交互（cursor、pointer-events、transitions）
6. 响应式变体放在最后

## 组件提取时机

在以下情况下提取为组件：
- 相同的工具类组合出现 3 次以上
- 这个组合有明确的语义意义
- 在多个文件中使用

不要只为了 DRY 而提取——工具类中适度重复是可以接受的。

## 响应式设计

- 移动优先：基础样式适配移动端，用 `sm:`、`md:`、`lg:` 适配更大屏幕
- 测试断点：320px、768px、1024px、1280px
- 禁止使用 `max-sm:` 或 `max-md:`——使用 min-width 断点

## 深色模式

- 使用 CSS 变量定义主题色，而非在每个类上使用 `dark:` 前缀
- 在 `@theme` 或 `:root` 中定义设计 Token

## 自定义值

- 谨慎使用 `[]` 任意值：`w-[137px]` 是一个警告信号
- 如果某个值需要使用超过一次，加到 `theme.extend` 中
- 优先使用命名间距步骤，而非魔法数字

## 性能注意

- PurgeCSS（Tailwind v3+ 内置）会自动移除未使用的类
- 禁止用字符串拼接构造类名——会导致 PurgeCSS 无法识别
- 安全模式：`cn('base-class', condition && 'conditional-class')`
