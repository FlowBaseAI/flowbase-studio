## Overview

The official Playwright MCP from Microsoft provides browser automation through accessibility tree snapshots rather than screenshots, making it fast and deterministic. Claude can navigate, interact, and extract data without relying on vision.

## Use Cases

- **E2E Testing**: Write and execute Playwright tests automatically
- **Form Filling**: Automate complex multi-step web forms
- **Data Extraction**: Scrape structured data using accessibility tree
- **Web Automation**: Automate repetitive browser tasks

## Configuration

No additional configuration needed — works out of the box.
