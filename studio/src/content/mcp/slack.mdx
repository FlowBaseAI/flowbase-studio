## 这个 MCP 能做什么？

Slack MCP 让 Claude 直接与 Slack 工作区交互，可以读取消息历史、发送通知、搜索内容，适合团队自动化工作流场景。

## 典型用途

**每日摘要**：「整理今天各频道的重要讨论，生成日报」

**自动通知**：「当构建完成时，自动发消息到 #deploy 频道」

**历史搜索**：「帮我在对话历史里找关于这个功能的讨论」

**周报生成**：「根据本周的频道内容，生成项目周报」

## 配置说明

需要在 Slack API 网站创建 App，获取 Bot Token，并邀请 Bot 加入相关频道。
