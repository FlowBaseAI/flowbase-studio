## 这个 MCP 能做什么？

MySQL MCP 让 Claude 直接连接 MySQL/MariaDB 数据库，适合使用 MySQL 的 PHP/Laravel/WordPress 等项目开发者。

## 典型用途

**数据查询**：「查询这个月注册的新用户数量和来源分布」

**SQL 辅助**：「帮我写一个复杂的 JOIN 查询」

**性能分析**：「分析这个慢查询，告诉我怎么优化」

**数据库文档**：「根据表结构自动生成数据字典」

## 配置说明

通过环境变量配置数据库连接信息，支持 MySQL 5.7+ 和 MariaDB。
