## 这个 MCP 能做什么？

Exa 是专为 AI 设计的搜索引擎，基于语义理解而非单纯关键词匹配。Exa MCP 让 Claude 获得更精准的搜索结果，特别适合技术文档、论文和深度内容的研究。

## 典型用途

**技术研究**：「帮我找关于 RAG 架构设计的深度文章」

**论文调研**：「搜索近半年关于 Agent 的研究成果」

**竞品分析**：「找出所有类似这个产品的解决方案」

**深度内容**：「搜索这个技术领域最权威的学习资源」

## Brave vs Exa

- Brave Search：适合通用信息和新闻搜索
- Exa：适合技术、学术和深度内容搜索
