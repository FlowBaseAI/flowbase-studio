# 国产 Agent 平台选型规范

## 目标

规定国内 Agent 平台选型必须按能力层级、集成成本、数据边界和中文支持评估。

## 必须遵守

- 先检查现有内容、权限和路由，避免重复和破坏功能。
- 对生产写入、发布、删除、付款、账号授权保留人工确认。
- 输出必须包含验证步骤、回滚方式和证据。
- Studio 内容必须服务 Claude Code 工作台导出，不做普通导航站。

## 禁止事项

- 禁止提交 node_modules、dist、日志和临时脚本。
- 禁止绕过 schema、构建或线上抽检。
- 禁止用未经验证的热点制造薄内容。

## 验收标准

- 规则能直接复制到项目中执行。
- 能约束 Agent 权限和输出质量。
- 符合国内团队实际使用场景。
