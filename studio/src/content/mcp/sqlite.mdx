## 这个 MCP 能做什么？

SQLite MCP 让 Claude 直接访问你的 SQLite 数据库文件，无需配置数据库服务器，适合独立开发者的本地数据分析场景。

## 典型用途

**App 数据查询**：「帮我查询应用数据库里的用户数据分布」

**数据分析**：「分析这个 SQLite 文件里的销售数据趋势」

**数据库调试**：「检查这个表的数据是否有异常」

**迁移辅助**：「分析这个数据库结构，帮我规划迁移方案」

## 配置说明

指定 SQLite 数据库文件路径：

```json
{
  "mcpServers": {
    "sqlite": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-sqlite", "--db-path", "/你的数据库.db"]
    }
  }
}
```
