## Overview

Puppeteer MCP provides headless Chrome automation capabilities. Claude can take screenshots, generate PDFs, interact with JavaScript-heavy pages, and scrape dynamic content.

## Use Cases

- **Screenshot Capture**: Take screenshots of any URL
- **PDF Generation**: Convert web pages to PDF
- **Dynamic Scraping**: Extract data from JavaScript-rendered pages
- **Visual Testing**: Capture before/after screenshots for UI changes
