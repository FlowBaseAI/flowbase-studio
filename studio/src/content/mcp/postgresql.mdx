## 这个 MCP 能做什么？

PostgreSQL MCP 让 Claude 直接连接到你的数据库。你可以用中文提问，Claude 会自动生成 SQL 查询并返回结果，不需要自己写 SQL。

## 典型用途

**数据查询**：「查询上个月销售额最高的10个产品」

**数据库理解**：「帮我解释这个数据库的表结构和关系」

**SQL 生成**：「帮我写一个统计用户留存率的 SQL 查询」

**数据分析**：「分析这张表的数据分布，找出异常值」

## 配置说明

提供 PostgreSQL 连接字符串：

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://用户名:密码@localhost/数据库名"]
    }
  }
}
```
