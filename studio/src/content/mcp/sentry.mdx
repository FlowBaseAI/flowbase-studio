## 这个 MCP 能做什么？

Sentry MCP 让 Claude 直接查询你的 Sentry 项目数据，帮助快速理解和修复生产环境的错误。

## 典型用途

**错误分析**：「分析过去 24 小时发生最多的 5 个错误」

**堆栈追踪解读**：「解释这个错误的堆栈追踪，告诉我根因」

**影响评估**：「这个 Bug 影响了多少用户，哪个版本开始出现的」

**修复建议**：「根据这个错误信息，建议如何修复」

## 配置说明

在 Sentry 设置 → API Keys 创建 Auth Token，需要 `event:read` 权限。
