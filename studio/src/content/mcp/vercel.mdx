## 这个 MCP 能做什么？

Vercel MCP 让 Claude 访问你的 Vercel 账户，查看部署状态、分析构建问题、管理项目配置。

## 典型用途

**部署监控**：「查看最近的部署状态，有没有失败的构建」

**日志分析**：「分析这次构建失败的日志，告诉我哪里出了问题」

**环境变量**：「列出生产环境的环境变量列表（不显示值）」

**域名管理**：「查看项目绑定的所有域名」

## 获取 Token

Vercel 控制台 → Settings → Tokens 创建访问令牌。
