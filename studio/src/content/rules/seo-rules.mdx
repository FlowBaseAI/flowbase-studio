# SEO Content Rules

## On-Page SEO

### Title Tags
- 50-60 characters maximum
- Include primary keyword near the beginning
- Each page must have a unique title
- Format: `Primary Keyword — Brand Name`

### Meta Descriptions
- 150-160 characters
- Include primary keyword naturally
- End with a compelling CTA
- Unique per page — no duplicates

### Heading Structure
- One H1 per page containing primary keyword
- H2s for major sections (include secondary keywords)
- H3s for subsections
- Never skip heading levels

## Content Quality

- Minimum 300 words for indexed pages, 1500+ for pillar content
- Primary keyword in first 100 words
- Keyword density 1-2% (don't stuff)
- Use semantic variations, not just exact match
- Answer the search intent directly and completely

## Technical Requirements

- Canonical tags on all duplicate/similar content
- Alt text on all images (descriptive, include keyword when relevant)
- Internal links to related pages (3-5 per article)
- External links to authoritative sources
- Schema markup for articles, products, FAQs where applicable

## URL Structure

- Lowercase, hyphen-separated words
- Include primary keyword
- Avoid stop words when possible
- Max 3-4 URL segments for key pages

## Core Web Vitals

- LCP under 2.5s
- FID under 100ms
- CLS under 0.1
