## Overview

The PostgreSQL MCP server provides Claude with direct access to your PostgreSQL database. Claude can inspect table schemas, run read-only queries, and help you understand your data structure.

## Use Cases

- **Schema Exploration**: Understand database structure instantly
- **Query Generation**: Generate complex SQL from natural language
- **Data Analysis**: Analyze and summarize your data
- **Migration Help**: Get Claude to review and suggest migrations

## Configuration

Provide your PostgreSQL connection string as an argument.

```json
{
  "mcpServers": {
    "postgres": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost/dbname"]
    }
  }
}
```
