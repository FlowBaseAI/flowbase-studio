# 安全开发规范

## 密钥管理

- 禁止在源代码中硬编码密钥、API Key 或凭证
- 使用环境变量——禁止提交 `.env` 文件
- 密钥一旦泄露必须立即轮换
- 生产环境使用专业密钥管理工具（Vault、AWS Secrets Manager）

## 输入验证

- 在系统边界验证所有用户输入——永远不要信任客户端数据
- 使用白名单允许可接受的值，拒绝其他所有值
- 渲染前做数据净化以防止 XSS
- SQL 使用参数化查询——禁止字符串拼接

## 认证与授权

- 密码使用 bcrypt（cost 12+）或 Argon2 加密——禁止明文存储
- 认证端点加速率限制
- JWT 使用短有效期 + Refresh Token
- 每个敏感操作都要检查授权——不能只靠 UI 隐藏来防护

## HTTP 安全头

```
Content-Security-Policy: default-src 'self'
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
Referrer-Policy: strict-origin-when-cross-origin
```

## 数据保护

- 敏感数据静态加密
- 全站使用 HTTPS——禁止混合内容
- 数据最小化原则——不收集不需要的数据
- 敏感数据访问记录审计日志

## 依赖项安全

- CI 流程中运行 `npm audit` / `pip-audit`
- 及时更新有安全补丁的依赖
- 添加新依赖前检查供应链风险
