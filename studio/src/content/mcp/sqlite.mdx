## Overview

SQLite MCP gives Claude direct access to SQLite database files on your local filesystem. Perfect for local development, data analysis, and projects that don't need a full database server.

## Use Cases

- **Local Data Analysis**: Query and analyze local SQLite databases
- **App Development**: Inspect your app's SQLite data during development
- **Data Migration**: Help plan and execute data migrations
- **Prototyping**: Quickly build data models and test queries
