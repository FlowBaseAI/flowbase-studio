## 这个 MCP 能做什么？

Grafana 官方 MCP 让 Claude 访问 Grafana 实例，读取 Dashboard 数据、查询指标，辅助运维分析。

## 典型用途

**指标分析**：「查看过去 1 小时的 API 响应时间趋势，有没有异常」

**告警分析**：「当前有哪些未解决的告警，按严重程度排列」

**性能报告**：「生成数据库连接池的使用率分析报告」

**容量规划**：「根据过去 30 天的趋势，预测未来内存需求」

## 来源

Grafana Labs 官方 MCP 服务器。
