## 这个 MCP 能做什么？

Figma MCP 让 Claude 读取 Figma 设计文件，提取组件信息、颜色值、间距等设计决策，帮助开发者更准确地实现设计稿。

## 典型用途

**设计转代码**：「读取这个 Figma 组件，帮我写对应的 React 代码」

**设计 Token 提取**：「提取这个设计文件中的颜色变量和字体规范」

**设计评审**：「检查这个页面的设计是否与设计系统规范一致」

**组件分析**：「列出这个 Figma 文件中所有使用的组件」

## 获取 Access Token

Figma 账户设置 → Security → Personal access tokens。
