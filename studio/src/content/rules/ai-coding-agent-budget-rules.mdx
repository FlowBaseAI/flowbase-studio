# AI Coding Agent 预算规范

## 目标

AI Coding Agent 预算规范 用于保证 FlowBase 用户在真实团队环境中使用 AI Agent 时有边界、有证据、有验收，不把工具能力变成不可控风险。

## 必须遵守

- 先明确任务目标、权限范围和输出格式。
- 涉及外部工具、仓库、服务器或客户数据时保留调用记录。
- 所有高风险动作必须有人类确认。
- 内容发布前必须去重并检查 SEO 意图。

## 禁止事项

- 禁止默认开放整个文件系统。
- 禁止把生产密钥写进配置示例。
- 禁止无验证就声称任务完成。
- 禁止为了数量制造重复内容。

## 验收标准

- 有清晰输入和输出。
- 有权限边界和风险说明。
- 有验证步骤。
- 能被国内团队直接理解和执行。
