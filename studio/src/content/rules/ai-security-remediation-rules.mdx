# AI 安全修复规范

## 目标

AI 安全修复规范 用于把热门 AI Agent 实践转成可执行团队规则，避免只有概念没有落地。

## 必须遵守

- 先确认任务边界。
- 保留输入、输出和验证证据。
- 高风险动作需要人工确认。
- 发布内容必须去重并适配国内用户。

## 禁止事项

- 禁止提交无来源结论。
- 禁止默认开放生产权限。
- 禁止绕过构建和线上验证。
- 禁止制造重复薄内容。

## 验收标准

- 规则能被直接执行。
- 包含权限和风险边界。
- 包含验收标准。
- 不破坏 Studio 工作台定位。
