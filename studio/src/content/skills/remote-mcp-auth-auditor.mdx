## Remote MCP 认证审计员

Remote MCP 认证审计员 面向 2026 年 AI Agent 安全、观测、身份和企业落地场景，强调国内团队可执行的流程和验收标准。

## 适用场景

- 远程 MCP 接入审计
- OAuth 风险评估
- 权限收敛

## 工作方式

1. 读取任务目标和约束。
2. 检查现有内容和权限边界。
3. 输出执行流程、风险点和验收标准。
4. 需要工具调用时保留证据。
