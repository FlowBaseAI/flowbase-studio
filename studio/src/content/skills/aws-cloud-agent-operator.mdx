## AWS 云 Agent 运维员

用只读云资源上下文辅助 Claude Code 做 AWS 排障和配置审查。

## 适用场景

- 云资源排查
- IAM 权限审查
- 运维报告

## 工作方式

1. 读取任务目标、仓库状态和用户约束。
2. 选择最小必要 MCP、文件和验证命令。
3. 输出分步方案，并明确哪些步骤需要人工确认。
4. 生成可复用的 Claude Code / Codex 指令。

## 输出要求

- 中文优先。
- 包含业务场景、风险边界和验收标准。
- 不生成重复资源或普通导航内容。
