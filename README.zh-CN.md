## 为什么使用 FlowBase Studio

Claude Code 项目通常需要在工作区准备阶段配置多个文件：

- `CLAUDE.md`
- MCP Config
- Skills Files
- Rules Files

FlowBase Studio 将这些配置集中到可视化界面中，让团队可以浏览资源库、配置项目，并导出可直接使用的配置文件。
