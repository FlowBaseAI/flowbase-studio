## Overview

Browser Use MCP gives Claude the ability to control a real Chromium browser. It can navigate URLs, interact with UI elements, extract structured data from pages, and automate complex web tasks.

## Use Cases

- **Web Scraping**: Extract structured data from any website
- **Form Automation**: Fill and submit forms automatically
- **Web Research**: Browse and summarize information from multiple sites
- **UI Testing**: Verify your web app's behavior end-to-end

## Requirements

Python 3.11+ and `pip install browser-use` required.
