## Overview

The Memory MCP server provides Claude with a persistent knowledge graph that survives across sessions. Claude can store and retrieve facts, relationships, and preferences automatically.

## Use Cases

- **User Preferences**: Remember user settings and preferences
- **Project Context**: Maintain context about long-running projects
- **Knowledge Building**: Build up domain knowledge incrementally
- **Personalization**: Make Claude's responses more personalized over time
