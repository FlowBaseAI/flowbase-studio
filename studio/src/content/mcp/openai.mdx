## 这个 MCP 能做什么？

OpenAI MCP 让 Claude 在工作中调用 OpenAI 的其他 AI 服务，构建多模型协作的工作流。

## 典型用途

**图像生成**：「用 DALL-E 生成这篇文章的配图」

**语音转写**：「用 Whisper 把这段音频转成文字」

**语义搜索**：「用 Embeddings 为这批文档建立向量索引」

**多模型协作**：让 Claude 负责推理，OpenAI 负责多媒体处理
