## 提示注入审计员

提示注入审计员 是面向 FlowBase Workspace 的中文 Skill，目标是把热门 AI 工具能力转成国内团队可执行、可验证、可复盘的工作流。

## 适用场景

- 外部内容审查
- MCP 输出风险识别
- 权限升级防护

## 工作方式

1. 先读取任务目标和约束条件。
2. 检查是否与现有内容或项目规则冲突。
3. 输出分步骤计划、风险点和验收标准。
4. 需要修改代码或部署时，要求保留证据。

## 输出要求

- 结构化任务清单
- 风险和权限提示
- 可执行下一步
- 适合复制到 Claude Code 的说明

## 注意事项

不要跳过去重、权限、验证和人工确认。FlowBase 的 Skill 要帮助用户稳定交付，而不是制造一次性提示词。
