## 这个 MCP 能做什么？

Docker MCP 让 Claude 可以直接与本地 Docker 环境交互，管理容器和镜像，无需记忆复杂的 CLI 命令。

## 典型用途

**容器管理**：「查看所有运行中的容器，哪个占用内存最多」

**日志查看**：「查看 nginx 容器最近的错误日志」

**故障排查**：「这个容器为什么一直重启，帮我分析日志」

**镜像管理**：「清理所有未使用的 Docker 镜像」

## 前置要求

本地已安装并运行 Docker Desktop 或 Docker Engine。
