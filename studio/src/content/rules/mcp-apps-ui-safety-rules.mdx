# MCP Apps UI 安全规范

## 目标

MCP Apps UI 安全规范 用于把 Agent 安全、身份、观测和企业协作要求固化为可执行规则。

## 必须遵守

- 明确任务边界和权限范围。
- 保存输入、输出、工具调用和验证证据。
- 涉及身份、授权、生产系统时必须人工确认。
- 内容和配置必须适合国内团队理解和执行。

## 禁止事项

- 禁止默认开放全部权限。
- 禁止隐藏失败和成本。
- 禁止绕过构建、测试或线上验证。
- 禁止制造重复薄内容。

## 验收标准

- 规则可执行。
- 包含权限和审计要求。
- 包含验收标准。
- 不破坏 Studio 工作台定位。
