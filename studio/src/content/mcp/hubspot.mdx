## 这个 MCP 能做什么？

HubSpot MCP 让 Claude 访问你的 HubSpot CRM 数据，辅助销售、市场营销和客户服务工作。

## 典型用途

**销售分析**：「分析本季度的销售漏斗，转化率在哪个阶段最低」

**联系人查询**：「找出 3 个月内没有互动的潜在客户」

**报告生成**：「生成本月的营销活动效果报告」

**客户洞察**：「分析企业客户的平均成交周期和金额」

## 获取 Token

HubSpot 开发者中心创建 Private App，获取访问令牌。
