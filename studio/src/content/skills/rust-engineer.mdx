## Rust 核心概念

### 所有权（Ownership）
```rust
// 每个值只有一个所有者
let s1 = String::from("hello");
let s2 = s1; // s1 被移动到 s2，s1 不再有效

// 使用引用（借用）避免移动
let s3 = String::from("world");
let len = calculate_length(&s3); // s3 仍然有效
```

### 借用规则
- 同一时间，要么有多个不可变引用，要么有一个可变引用
- 引用必须始终有效（生命周期保证）

### 错误处理
```rust
// Result 类型，不用 exception
fn read_file(path: &str) -> Result<String, io::Error> {
    fs::read_to_string(path)
}

// ? 操作符简化错误传播
fn process(path: &str) -> Result<(), io::Error> {
    let content = fs::read_to_string(path)?;
    println!("{}", content);
    Ok(())
}
```

## Rust 惯用法

### 模式匹配
```rust
match option_value {
    Some(x) if x > 0 => println!("Positive: {}", x),
    Some(x) => println!("Non-positive: {}", x),
    None => println!("Nothing"),
}
```

### 迭代器链
```rust
// 函数式风格，零开销抽象
let sum: i32 = (1..=100)
    .filter(|x| x % 2 == 0)
    .map(|x| x * x)
    .sum();
```

### Trait（接口）
```rust
trait Greet {
    fn greet(&self) -> String;
    fn greet_loudly(&self) -> String {
        self.greet().to_uppercase()  // 默认实现
    }
}
```

## 常见坑和解决方案

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| cannot borrow as mutable | 已有不可变借用 | 限制借用范围 |
| does not live long enough | 生命周期问题 | 使用 Arc 或调整结构 |
| cannot move out of `*self` | 方法消费 self | 用 Clone 或 &self |

## unsafe 使用原则

- unsafe 只用于：FFI、原始指针操作、实现 Send/Sync
- unsafe 块尽量小，只包含必要代码
- 用安全的 API 包装 unsafe 代码
- 详细注释为什么这里是安全的
