## 这个 MCP 能做什么？

Tavily 搜索 MCP 能把 tavily 相关能力接入 Claude Code Workspace，让国内团队在一个可视化工作台中选择、配置并导出项目。它适合与 GitHub、Filesystem、Playwright 和 SEO 类 Skill 搭配使用。

## 国内团队使用场景

- 为 Claude Code 提供可调用工具上下文
- 把热门国际工具转成国内团队可落地流程
- 在 Studio 中作为 Workspace 数据源选择

## 配置示例

```json
{
  "mcpServers": {
    "tavily": {
      "command": "npx",
      "args": [
      "-y",
      "tavily-mcp"
]
    }
  }
}
```
