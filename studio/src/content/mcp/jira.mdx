## 这个 MCP 能做什么？

Jira MCP 让 Claude 直接访问 Jira 项目数据，帮助项目管理和开发团队提升效率。

## 典型用途

**Issue 查询**：「查看本 Sprint 还有多少 P0 Bug 未解决」

**任务创建**：「根据这个 Bug 描述创建一个详细的 Jira Issue」

**Sprint 报告**：「生成本 Sprint 的完成情况摘要」

**工作量分析**：「统计过去一个月每个团队成员关闭的 Issue 数量」

## 获取 API Token

Atlassian 账户设置 → Security → Create and manage API tokens。
