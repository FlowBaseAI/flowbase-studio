## 这个 MCP 能做什么？

GitHub MCP 让 Claude 拥有直接操作 GitHub 的能力。你可以用自然语言描述需求，Claude 会自动完成对应的 GitHub 操作。

## 典型用途

**代码搜索**：「帮我在这个仓库里找所有处理用户认证的文件」

**Issue 管理**：「给这个 bug 创建一个详细的 Issue，包括复现步骤」

**PR 审查**：「分析这个 PR 的改动，找出潜在问题」

**仓库分析**：「分析这个开源项目的代码结构，告诉我从哪里开始读」

## 环境配置

需要 GitHub Personal Access Token，在 GitHub Settings → Developer Settings → Personal Access Tokens 创建，选择 `repo` 权限。

```json
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_TOKEN": "ghp_你的token"
      }
    }
  }
}
```
