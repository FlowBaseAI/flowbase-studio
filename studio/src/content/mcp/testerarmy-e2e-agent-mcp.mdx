## 这个 MCP 能做什么？

自然语言 E2E 测试 MCP 面向 Claude Code 中文工作台，帮助团队把 自然语言 E2E 测试 接入可选择、可配置、可导出的 Agent 工作流。

## 国内团队使用场景

- 企业项目、云资源、AI 搜索、测试和 Agent 治理场景。
- 需要把外部系统变成 Claude Code 可控工具源。
- 需要在导出前明确权限、参数和审计边界。

## 配置示例

```json
{
  "mcpServers": {
    "testerarmyE2E": {
      "command": "npx",
      "args": [
      "-y",
      "testerarmy-e2e-agent-mcp"
]
    }
  }
}
```

## 使用建议

- 先启用只读模式。
- 为高危写入动作加人工确认。
- 每次导出后记录版本、负责人和验证结果。
