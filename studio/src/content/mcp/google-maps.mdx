## 这个 MCP 能做什么？

Google Maps MCP 让 Claude 直接调用 Google Maps Platform API，处理地理位置相关的查询和操作。

## 典型用途

**地点搜索**：「在北京朝阳区找评分 4.5 分以上的咖啡馆」

**路线规划**：「从上海虹桥到浦东机场最快路线是什么」

**地理编码**：「把这个地址列表转换为经纬度坐标」

**周边查询**：「这个坐标 2 公里内有哪些加油站」

## 配置说明

在 Google Cloud Console 申请 Maps Platform API Key，启用 Maps JavaScript API、Places API、Geocoding API。
