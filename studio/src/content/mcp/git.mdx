## 这个 MCP 能做什么？

Git MCP 让 Claude 直接读取本地 Git 仓库的历史记录、变更内容和分支信息，为代码分析和版本管理提供深度上下文。

## 典型用途

**Commit 信息生成**：「根据这次改动，帮我写一条规范的 Commit 信息」

**变更分析**：「这两个版本之间改了什么，有没有风险点」

**代码溯源**：「这个函数是什么时候加的，当时为什么改」

**分支对比**：「对比 main 和 dev 分支的差异，做个总结」
