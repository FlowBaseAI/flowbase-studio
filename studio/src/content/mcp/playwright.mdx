## 这个 MCP 能做什么？

Playwright MCP 是微软官方发布的浏览器自动化工具。它让 Claude 能够控制真实的 Chrome 浏览器，不依赖截图，而是通过页面的无障碍树（Accessibility Tree）来理解和操作网页，更快更稳定。

## 典型用途

**网页抓取**：「帮我抓取这个网站的所有产品信息，整理成表格」

**自动填表**：「打开这个网页，自动填写并提交表单」

**端到端测试**：「测试这个功能是否正常工作」

**网页截图**：「截取这个页面的内容」

## 配置说明

开箱即用，无需额外配置：

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp"]
    }
  }
}
```
