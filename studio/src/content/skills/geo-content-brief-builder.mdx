## GEO 内容简报生成器

GEO 内容简报生成器 面向国内团队的 Claude Code 工作台场景，把热点需求转成可复制执行的任务说明。

## 适用场景

- AI 搜索内容选题
- 官网文章 Brief
- 关键词和问题聚类

## 工作方式

1. 读取任务目标、现有仓库和业务约束。
2. 明确需要调用的 MCP、文件和验证命令。
3. 输出分步执行方案，先小范围验证再扩大。
4. 记录失败原因、回滚方式和上线证据。

## 输出要求

- 中文优先，结构化清晰。
- 包含 SEO 或业务关键词。
- 包含风险边界和验收标准。
- 适合复制到 Claude Code / Codex 中执行。
