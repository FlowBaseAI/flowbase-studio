## 这个 MCP 能做什么？

Resend MCP 让 Claude 在工作流中发送事务性邮件，适合通知、报告分发和自动化场景。

## 典型用途

**报告分发**：「把今天的数据分析报告发送给团队」

**通知邮件**：「任务完成后自动发送通知邮件」

**测试邮件**：「发送一封测试邮件验证模板效果」

**批量通知**：「给这个列表里的用户发送产品更新通知」

## 特点

Resend 专为开发者设计，支持 React Email 模板，交付率高，有良好的中国访问记录。
