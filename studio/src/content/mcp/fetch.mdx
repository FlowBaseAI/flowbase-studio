## 这个 MCP 能做什么？

Fetch MCP 让 Claude 可以直接访问任意 URL，将网页内容转换为 Markdown 文本格式，方便进一步分析和处理。

## 典型用途

**文档读取**：「帮我读取这个 API 文档，告诉我怎么用」

**文章摘要**：「抓取这篇文章，用中文总结要点」

**内容对比**：「分别抓取这两个页面，对比它们的差异」

**数据提取**：「从这个页面提取所有表格数据」

## 与浏览器 MCP 的区别

- Fetch MCP：只读，速度快，适合静态内容
- Playwright/Browser Use：可交互，适合动态页面和需要操作的场景
