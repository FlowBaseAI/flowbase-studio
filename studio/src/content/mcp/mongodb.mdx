## 这个 MCP 能做什么？

MongoDB MCP 让 Claude 直接连接 MongoDB，用自然语言描述需求，Claude 自动生成并执行查询。

## 典型用途

**数据查询**：「查找过去 30 天内下了多次订单的用户」

**聚合分析**：「按城市统计用户分布，排序展示」

**Schema 分析**：「分析这个集合的文档结构，找出字段不一致的记录」

**索引建议**：「根据这些查询模式，建议应该创建哪些索引」
