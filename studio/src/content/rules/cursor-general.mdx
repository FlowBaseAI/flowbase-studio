# Cursor 通用规范

## 代码风格

- 缩进一致（JS/TS 用 2 个空格，Python 用 4 个空格）
- 有意义的变量名——除循环计数器外禁止单字母变量
- 禁止魔法数字——使用命名常量
- 提交前删除所有注释掉的代码

## 行为规范

- 意图不明时不要假设——有疑问就问
- 进行多处修改时展示完整文件，而非只显示 diff
- 优先沿用已有模式，而非引入新的
- 不要悄悄修改请求范围之外的内容

## 沟通规范

- 重要修改前先解释方案
- 有多种可行方案时，列出选项并说明各自权衡
- 明确标注潜在的破坏性变更
- 禁止在请求范围之外悄悄修改内容

## 文件操作

- 没有明确指令禁止删除文件
- 除非明确要求，保留已有注释
- 保持现有代码风格（即使你会有不同做法）
- 不要格式化与任务无关的代码

## 错误处理

- 禁止默默吞掉异常
- 错误信息要包含有用的上下文
- 对复杂操作加入日志以方便调试
- 在函数入口处验证输入
