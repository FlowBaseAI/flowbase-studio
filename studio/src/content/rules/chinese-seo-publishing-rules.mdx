# 中文 SEO 发布规范

## 核心原则

FlowBase 的中文内容必须服务真实搜索意图：用户搜这个词，是想配置工具、解决问题、做选型、找模板，还是排查错误。文章和资源库都要围绕这个意图写。

## 发布前去重

每次新增内容前必须检查：

- 文章：`title`、`slug`、`description`、`tags`
- MCP：`name`、`name_zh`、`github_url`
- Skills：`name`、`name_zh`、`file_name`
- Rules：`name`、`name_zh`、`file_name`

禁止只换标题但内容高度重复。相似主题优先更新旧内容，而不是新增一篇薄内容。

## 标题规则

标题必须包含一个真实搜索词，例如：

- Claude Code MCP 配置
- Codex CLI 使用教程
- 飞书 MCP 接入
- AI Coding Agent 工作流
- Cursor Rules 模板

推荐标题结构：

- `主关键词 + 使用场景`
- `主关键词 + 配置教程`
- `主关键词 + 国内团队落地方案`
- `工具 A vs 工具 B + 选型`

## Meta 描述

描述必须包含：

- 主关键词
- 目标用户
- 解决的问题
- 可获得的结果

不要写空泛形容词，例如“强大”“全面”“领先”。要写用户能理解的收益，例如“把飞书需求转成 Claude Code 项目配置”。

## 内容结构

每篇中文 SEO 内容至少包含：

1. 一句话介绍
2. 为什么现在需要
3. 适合哪些人
4. 解决什么问题
5. 配置或执行步骤
6. 常见错误
7. 推荐搭配
8. 延伸阅读

## 国内语境

优先覆盖国内团队真实使用场景：

- 飞书需求和知识库
- GitHub / Gitee 项目协作
- 宝塔或 VPS 部署
- 独立开发者网站
- 小红书、公众号、知乎内容增长
- Cursor、Claude Code、Codex CLI、MCP 混合使用

## 内链规则

每篇文章至少添加 2-3 个相关内链：

- 工具教程链接到工作流文章
- 工作流文章链接到 MCP 安全和权限内容
- SEO 内容链接到内容工厂或自动化文章

## 禁止事项

- 禁止为了数量制造重复内容。
- 禁止只翻译英文资料，不结合国内场景。
- 禁止把 Studio 写成普通资源导航站。
- 禁止没有验证步骤的“全自动”承诺。
- 禁止堆关键词影响可读性。

## 最终检查

发布前确认：

- 标题是否有搜索词？
- 描述是否能吸引点击？
- 内容是否回答用户问题？
- 是否与现有内容重复？
- 是否有国内使用场景？
- 是否有内链和推荐搭配？
