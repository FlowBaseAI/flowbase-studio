## 这个 MCP 能做什么？

Brave Search MCP 给 Claude 接入实时互联网搜索能力。Claude 可以主动搜索最新信息，解决训练数据有截止日期的问题。

## 典型用途

**最新资讯**：「搜索今天 AI 领域有什么重要新闻」

**技术调研**：「帮我搜索这个框架的最新版本有什么变化」

**竞品研究**：「搜索市场上类似产品的价格和用户评价」

**事实核查**：「帮我确认这个说法是否准确，找相关来源」

## 获取 API Key

前往 [Brave Search API](https://brave.com/search/api/) 申请，每月有免费配额。
