## 这个 MCP 能做什么？

GitHub Actions MCP 让 Claude 直接访问 GitHub Actions 工作流数据，帮助分析 CI/CD 问题和优化流水线。

## 典型用途

**构建状态**：「查看最近 10 次 CI 运行，哪些失败了」

**失败分析**：「这次构建失败的详细日志是什么，问题在哪」

**工作流管理**：「列出所有 GitHub Actions 工作流，哪个运行最频繁」

**性能优化**：「分析这个工作流的耗时，哪个步骤最慢」
