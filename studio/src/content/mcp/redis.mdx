## 这个 MCP 能做什么？

Redis MCP 让 Claude 直接连接 Redis，查看和分析缓存数据，帮助调试缓存策略和性能问题。

## 典型用途

**缓存调试**：「查看这个用户 Session 的缓存数据是否正确」

**Key 分析**：「统计 Redis 中各类型 Key 的数量和内存占用」

**过期策略**：「检查这些 Key 的 TTL 是否合理」

**性能分析**：「分析 Redis 的内存使用情况，找出占用最大的 Key」
