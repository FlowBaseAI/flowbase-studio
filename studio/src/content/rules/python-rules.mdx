# Python 编码规范

## 代码风格（PEP 8）

- 缩进使用 4 个空格——禁止 Tab
- 最大行长度 88 字符（Black 默认值）
- 顶层定义之间两个空行
- 方法之间一个空行
- 格式化使用 `black`，代码检查使用 `ruff`

## 类型注解

- 所有函数签名必须有类型注解（参数 + 返回值）
- 前向引用使用 `from __future__ import annotations`
- Python 3.10+ 使用 `X | None` 而非 `Optional[X]`
- Python 3.9+ 使用 `list[str]` 而非 `List[str]`
- `Any` 只作最后手段，必须加注释说明原因

## 现代语法

- 字符串格式化使用 f-strings，而非 `.format()` 或 `%`
- 赋值表达式使用海象运算符 `:=`（Python 3.10+）
- 长 if/elif 链使用 `match` 语句（Python 3.10+）
- 结构化数据使用 `dataclasses` 或 `pydantic`，而非裸字典
- 所有资源管理使用上下文管理器

## 函数规范

- 函数职责单一，保持精短
- 默认参数只求值一次——禁止可变默认值
- 真正可变参数才用 `*args` 和 `**kwargs`
- 超过 3 个参数时优先使用关键字参数以提高可读性

## 错误处理

- 捕获具体异常——禁止裸 `except:`
- 预期中可忽略的错误使用 `contextlib.suppress`
- 自定义异常继承自合适的基类
- 错误信息要包含有用的上下文

## 项目结构

- 项目元数据全部放在 `pyproject.toml`
- 可安装包使用 `src/` 布局
- 只在必要时加 `__init__.py`（命名空间包不需要）
