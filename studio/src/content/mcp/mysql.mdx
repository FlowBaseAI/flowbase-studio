## Overview

MySQL MCP server provides Claude with access to MySQL and MariaDB databases, enabling schema inspection, query generation, and data analysis.

## Use Cases

- **Database Documentation**: Auto-generate schema documentation
- **Query Optimization**: Get query improvement suggestions
- **Data Exploration**: Analyze and understand your data
- **Migration Planning**: Plan and review schema migrations
