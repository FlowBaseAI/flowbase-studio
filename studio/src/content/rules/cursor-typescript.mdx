# Cursor TypeScript 规范

## 严格模式

- 始终在 `strict: true` 环境下工作——禁止降级
- 完成任务前必须解决所有 TypeScript 错误
- 禁止 `@ts-ignore` 或 `@ts-expect-error`（除非有注释说明原因）
- 优先编译时错误，而非运行时错误

## 类型定义

- 跨文件使用的类型必须导出
- 类型与其主要使用场景放在一起
- 使用描述性类型名：`UserId` 而非 `id`，`ApiResponse<T>` 而非 `Response`
- 复杂泛型类型用 JSDoc 注释说明

## 推荐模式

```typescript
// 优先使用
const config = { port: 3000 } as const
type Config = typeof config

// 而非
const config: { port: number } = { port: 3000 }
```

```typescript
// 优先使用可辨别联合类型
type Result<T> = { ok: true; data: T } | { ok: false; error: string }

// 而非为预期失败抛出异常
```

## 代码生成规范

- 先定义类型，再写实现
- 运行时验证 + TypeScript 类型推断使用 `zod`
- 类型检查优先使用 `satisfies` 而非 `as`
- 字符串模式验证使用模板字面量类型
