## 这个 MCP 能做什么？

钉钉工单 OpenAPI MCP 是面向 Claude Code Workspace 的接入蓝图，用于把 钉钉审批、工单和项目协作 纳入可选择、可配置、可导出的工作台能力。

## 国内团队使用场景

- 在 FlowBase Studio 中作为项目上下文或自动化工具源。
- 连接企业内部知识、工单、数据、云资源或分析系统。
- 为 AI Agent 任务保留权限、参数和审计边界。

## 配置示例

```json
{
  "mcpServers": {
    "dingtalkWorkOrder": {
      "command": "npx",
      "args": [
      "-y",
      "@modelcontextprotocol/server-openapi",
      "--name",
      "dingtalk-work-order"
]
    }
  }
}
```

## 使用建议

- 先在测试空间连接，不直接使用生产密钥。
- 只开放最小读取或写入权限。
- 对删除、发送、支付、发布类动作增加人工确认。
