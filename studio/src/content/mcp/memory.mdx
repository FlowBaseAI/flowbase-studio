## 这个 MCP 能做什么？

Memory MCP 通过知识图谱技术，让 Claude 在对话之间保持记忆。Claude 可以主动存储和检索重要信息，不再每次都需要重新介绍背景。

## 典型用途

**个人偏好**：「记住我喜欢简洁的代码风格，以后都按这个要求」

**项目背景**：「记录这个项目的技术选型决策，以后参考」

**知识积累**：「把这次研究的结论存起来，以后可以调用」

**个性化助手**：「记住我的团队成员和各自职责」

## 使用方式

Claude 会根据对话内容主动决定存储哪些信息，你也可以明确告诉它「记住这件事」。
