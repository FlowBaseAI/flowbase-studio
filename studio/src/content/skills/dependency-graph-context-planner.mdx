## 依赖图上下文规划员

依赖图上下文规划员 面向国内团队的真实 AI Agent 落地场景，强调去重、权限边界、验证证据和可复盘输出。

## 适用场景

- 大型仓库上下文选择
- 重构影响面分析
- Token 成本控制

## 工作方式

1. 读取任务目标和约束。
2. 检查已有项目内容和规则。
3. 生成结构化计划。
4. 输出风险、验证和交付格式。

## 输出要求

- 任务计划
- 风险清单
- 验收标准
- 可复制到 Claude Code/Codex 的执行说明
